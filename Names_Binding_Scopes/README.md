## System Documentation

A Python project demonstrating a Course Registration Policy Engine and Scope Resolver as part of the Programming Languages Lab.

### Assignment Requirements Covered

1. Named constants demonstration (`1_named_constants.py`)
2. Registration validator + scope vs lifetime (`2_registration_validators.py`)
3. Static vs dynamic scoping core (`3_scope_resolver.py`)
4. Two call scenarios with traces (`4_scope_scenario.py`)
5. Referencing environment table (`5_env_table.py`)

### Files Included

* `1_named_constants.py`        - Named constants demonstration
* `2_registration_validators.py` - Registration validator + scope vs lifetime
* `3_scope_resolver.py`         - Static vs dynamic scoping core
* `4_scope_scenario.py`         - Two call scenarios with traces
