## Projects Included

This repository is divided into two main projects. You can run them directly from the root of this repository.

### 1. [Lua Coroutine Exercises](./Lua_Coroutine_Exercises/)
A Lua implementation of **Question 10: Supermarket Checkout and Stock Consistency** using coroutines.
- Simulates multiple supermarket checkout counters running as Lua coroutines.

**How to Run:**
Make sure you have Lua 5.4 installed.
```bash
cd Lua_Coroutine_Exercises
lua q10_checkout.lua
```
*(For full details, see the [Project 1 README](./Lua_Coroutine_Exercises/README.md))*

### 2. [Names, Bindings and Scopes](./Names_Binding_Scopes/)
A Python project demonstrating a Course Registration Policy Engine and Scope Resolver.
- Explores concepts such as named constants, registration validators, and static vs dynamic scoping.

**How to Run:**
Make sure you have Python installed. You can run the complete integrated execution:
```bash
cd Names_Binding_Scopes
python 6_main_execution.py
```
*(For running individual Python files or seeing more details, refer to the [Project 2 README](./Names_Binding_Scopes/README.md))*
